# PROJECT TITAN

MCP-Schnittstelle für die Arbeit mit GIANTS-Editor-Projekten.

## Ziel

PROJECT TITAN soll MCP-Clients wie Codex kontrollierte Werkzeuge für GIANTS-Editor-Projekte bereitstellen. Die Entwicklung und Tests mit dem Editor laufen lokal auf Windows; die genaue Verbindung zwischen MCP-Server und Editor ist noch festzulegen.

## Erster Meilenstein

1. Die unterstützten Erweiterungs- und Integrationsmöglichkeiten des GIANTS Editors prüfen.
2. Einen lokalen Bridge-Entwurf festlegen, der auch ohne laufenden Editor sicher getestet werden kann.
3. Einen kleinen Prototyp mit Statusabfrage und klar begrenzten Aktionen umsetzen.

## Entwicklungsstand

Das Repository startet mit dieser Projektbeschreibung. Programmiersprache, Bridge-Protokoll und konkrete MCP-Werkzeuge werden nach Prüfung der Editor-Schnittstellen festgelegt.
